# 🧮 Smart Calculator

A beginner-friendly Python calculator that performs basic mathematical operations.

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- User input support
- Simple terminal interface

---

# 🚀 How to Run

## 1. Install Python
Make sure Python 3 is installed on your computer.

## 2. Run the program

```bash
python main.py
```
